## It-tools工具

> 为开发者提供的一系列便捷在线工具，具有出色的用户体验。
>
> [github](https://github.com/CorentinTh/it-tools)





### 1. 安装

```shell
services:
  it-tools:
    image: corentinth/it-tools:latest
    container_name: it-tools
    restart: always
    # 映射端口：宿主机 1006 -> 容器 80
    ports:
      - 1006:80
    # 交互模式配置（对应 -it）
    stdin_open: true
    tty: true
    # 资源限制（可选，推荐）
    deploy:
      resources:
        limits:
          memory: 128M
```
