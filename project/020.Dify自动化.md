## Dify自动化

> Dify是一个用于构建智能体工作流的开源平台。
>
> [github](https://github.com/langgenius/dify)



### 1. 安装

> 安装
>
> [blog](https://docs.dify.ai/en/self-host/quick-start/docker-compose)

```shell
# 1. 克隆代码
git clone https://github.com/langgenius/dify.git

# 开始
cd dify/docker
cp .env.example .env
docker compose up -d
```





### 2. 使用

> 使用

1. 打开管理员初始化页面以设置管理员帐户：

   ```
   # Local environment
   http://localhost/install
   
   # Server environment
   http://your_server_ip/install
   ```

2. 完成管理员账户设置后，请登录 Dify：

   ```
   # Local environment
   http://localhost  
   
   # Server environment
   http://your_server_ip
   ```
