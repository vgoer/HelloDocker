## Artalk

> Artalk自托管评论系统
>
> [github](https://github.com/ArtalkJS/Artalk)







### 1. 安装

```shell
mkdir artalk
nano docker-compose.yaml
```

```yaml
services:
  artalk:
    image: artalk/artalk-go
    container_name: artalk
    environment:
      - TZ=Asia/Shanghai
      - ATK_LOCALE=zh-CN
      - ATK_SITE_DEFAULT=vgoer's Blog
      - ATK_SITE_URL=https://atk.vgoer.cn
    ports:
      - 1003:23366
    volumes:
      - ./data:/data
    restart: always
```

> 创建管理员：

```shell
docker exec -it artalk artalk admin
```
